# 動態模式瀏覽器檢查 · 2026-10-03

以本機 IAB 檢查 `mirea.html`；QA 隔離頁使用可編輯版本的同一套模型與引擎。

- 實際滑鼠拖動：角色隨目標方向移動，眼睛跟隨；上半身與骨盆讀值有不同跟進速度。
- 游標／流動展示／接點測試：模式狀態及說明正確，自動模式播放斜向循環或極端反轉。
- 持傘 210% 與雙腿 200% 特寫：原畫邊緣、交叉腿和握傘位置保持連續。
- 暫停後拖曳平移：相同視線快照保留，只有檢視 transform 改變。
- 鍵盤 0、+、滾輪縮放：檢視可回全身，125% 的讀值與滑桿一致；滾輪操作在舞台內縮放。
- 部位層次 Home=0、End=100%：0 時兩個群組位移／旋轉歸零，可與整體追蹤比較。
- 原圖對照／重設：顯示原圖、恢復播放器，重設回到游標模式與預設數值。
- 減少動態隔離頁：切到流動展示仍保持靜態，群組與漂移零值；400% 縮放可用，關閉模擬偏好後恢復播放。
- WebGL 回退隔離頁：原圖保留，動態模式停用，持傘特寫可用。
- 正常預覽頁沒有 console error。

引擎另有 39 項測試，網站 10 項測試；typecheck、build 通過。模型驗證 9,000 幀沒有反向三角形或全域縮幅，腿與鞋子的最大相對邊長誤差約 0.00085%。持傘結構在群組強度 0、0.5、1 的反轉測試中保留共同剛性變換。

實體手機觸控與直接雙擊離線 HTML 未實測。獨立膝關節、步行、素材遮擋補全和完整 Live2D／Spine 播放器不在本版能力中。
