# Character-led scene design

Read the existing character brief and actual illustration. Identify activity, identity, personality, fixed appearance, style, palette, lighting and viewpoint. Text alone supports scene planning but does not prove a visual match. Preserve the character; do not change outfit or accessories incidentally. Follow a user-specified world/location even if it was their starting point.

Define: "The character does [activity] in [concrete place], conveying [feeling]. The main visual anchor is [feature]." This controls hierarchy better than a list of repeated motifs.

For multiple requested scenes, differentiate function, visual anchor, light/time, activity, depth or composition. Exploration/world, private/daily and performance/event are possible roles, not a mandatory three-scene formula.

Start with one main anchor, a few supporting elements, a material language, coherent light and quiet character/text space. Ornate narrative scenes may contain more, but still need a readable focal hierarchy.

Plan foreground framing without cutting off the character, a usable middle-ground standing/sitting/action area, and a background that establishes scale without competing. Sitting needs a seat; prop interaction needs believable height/contact. Match the approved illustration's perspective/light or adjust the background first. Separately version any authorized character relighting.

An independent background normally contains no people or fake text, supports its intended aspect ratio and reserves character/text space. Do not claim a desktop crop is a finished mobile composition if landmarks or safe areas need rearrangement.

Background first: plan purposes, create separate backgrounds, inspect perspective/light/contact space/density, composite using those actual backgrounds and the actual character reference, then compare landmarks/furniture/light.

Scene spec: ID/purpose, retained baseline version, activity, feeling, anchor, supporting elements, materials/light, character contact position, text safe area/aspect ratio, distinction from other scenes, requested output (background/composite/both).

Handoff brief: identity/personality/activity, fixed features, style/materials, palette, anatomy, actual image path/version, alpha and QA status, allowed variations and pending work. Read [quality gates](quality-and-delivery-guide.md) for final inspection.
