# Quality and delivery gates

Apply only gates relevant to the requested deliverable.

## 1. Character consistency

Use the latest approved baseline. Preserve face/head proportions, eyes or key features, silhouette, hairstyle/body structure, outfit, accessories, palette, art style and materials. Expression, gaze, pose, camera and scene may vary. Requested outfits or special editions are separately versioned. Do not explain accidental design drift as an intentional variant.

## 2. Character structure

Inspect each character image against its defined anatomy. A standard humanoid generally has two arms/hands and two legs; an unobscured human hand generally has five naturally connected fingers. Natural occlusion can hide parts but cannot justify duplicates, fused fingers or wrongly connected wrists. Check knees, ankles, shoes and sitting contact.

For nonhumans, use the actual defined wings, claws, tentacles, tails, mechanical components or missing limbs. Hair/ribbons/sleeves must not accidentally become extra limbs. Reject added/missing parts, floating components, disconnected joints, penetrations or invalid contact. Preserve passed assets, repair only failed ones and inspect the repair before claiming it is fixed.

## 3. Pose and expression

Prefer one principal action initially. Introduce difficult hands, extreme perspective or several props only when the behavior calls for them. Expression sets need readable emotional differences without personality drift, and separate reusable outputs.

## 4. Scene hierarchy and diversity

Start with one visual anchor, limited supporting detail, coherent light/materials and quiet space. This is a starting point, not a restriction on requested ornate artwork. Distinguish multiple scenes by use, activity, lighting, time or composition while sharing the world. Repeating character motifs in every corner does not establish a convincing environment.

## 5. Background-to-composite relationship

Each composite uses one actually completed background. Keep landmarks, furniture, seats, windows and lights consistent. Explain character scale, perspective and foot/seat contact. Do not invent a second similar scene while claiming it uses the first. Sitting needs a usable seat.

## 6. Transparency

Verify format and real alpha when files are accessible, including edge halos and leftover background. Otherwise report alpha unverified. A checkerboard painted into an image is not transparency.

## 7. Character board and package

The board is an index assembled from passed assets, not a newly generated central character and not a replacement for original files. Use controlled layout for exact text.

When a ZIP is requested, check filenames, versions, independent character/pose/expression files, background/composite mapping, alpha status and a README listing baseline, inventory and limitations. Exclude failed drafts. Remove empty directories. Suggested folders: Character, Expressions, Actions, Backgrounds, Composites, Preview.
