# Illustration and staged image creation

Establish one reusable baseline, then extend it. Read [quality gates](quality-and-delivery-guide.md) when creating or editing images.

## Choose the requested stage

| Scope | Deliver |
| --- | --- |
| New character | Brief and baseline illustration |
| Existing character expressions | Separate transparent expression images |
| Existing character poses | Purposeful separate pose images |
| Background only | Independent scene; no unnecessary character variants |
| Composite | Actual approved character + actual completed background |
| Full asset pack | Agreed inventory, dependent stages, inspection, originals and requested package |

Lock facial/head proportions, hairstyle or body silhouette, outfit, signature accessories, palette, proportions, style, materials and defined appendages. Use the actual baseline image as an editing reference; "same as last time" is insufficient.

For a reusable baseline, choose a readable natural pose, keep head ornaments and body extremities in frame, leave margin and avoid stacking gestures or props unnecessarily. White or checkerboard pixels are not transparency; use real alpha output when available.

Expressions should be recognizably different while retaining personality. A reserved character's anger may remain subtle. If the requested set distinguishes happiness and exuberant joy, reflect that distinction rather than slightly changing a mouth corner. Each output is independent, not a four-panel collage.

Pose variants need a purpose: singing, inviting, reading, sitting, operating a prop. Start with one main action; add complex hands, perspective or multiple props only when justified. Preserve the character's actual nonhuman anatomy when applicable.

Inspect each image for identity and expected anatomy. Repair only failures and keep successful versions. For scene/composite work, follow [scene design](theme-and-scene-guide.md): background first, actual reference images, consistent landmarks/light/perspective and valid ground or seat contact.

Use available native image tools when images are requested. Keep one clearly scoped asset per generation/edit. If references/tools are unavailable, deliver marked specifications instead of claiming generation. Save useful originals to the project and version repairs. Verify actual format, dimensions and alpha when files can be read.

For full packs, first agree the inventory, establish the baseline, inspect variants, create requested backgrounds, inspect them, composite against those exact files, and assemble a character board from completed assets. Create a ZIP only when asked. Report generated/inspected, alpha verified, unverified, or failed/excluded accurately.
