# Optional design reference library

Migrated source pointers from the original character skill. These are external reading options, not runtime dependencies. Open the relevant source before attributing current facts or visual observations to it; the pointers do not prove current site content. Select only sources useful to this request. Keep source observations separate from original design inferences.

## Original-character personality

[Primary source](https://www.clipstudio.net/how-to-draw/archives/154434)

Translate a personality adjective into speech and behavior before designing appearance.

## Silhouette, proportions and style

[Primary source](https://www.clipstudio.net/en/characterart/art-style/)

Test recognizability in a small silhouette; lock your own features rather than increasing detail.

## Beginner character-art guide

[Primary source](https://www.clipstudio.net/en/characterart/beginners-guide/)

Turn a few preferences into a provisional brief; distinguish text specifications from actual images.

## Piapro virtual singers

[Primary source](https://piapro.net/intl/en_character.html)

Study how a core identity survives seasonal extensions; create your own name, shape and palette.

## Character identity and content: Usada Pekora

[Primary source](https://hololive.hololivepro.com/en/talents/usada-pekora/)

Connect daily preferences, greeting and sustainable content; do not transfer the original accessory/catchphrase combination.

## Character contrast: Kuromi

[Primary source](https://www.sanrio.co.jp/characters/kuromi/)

Give the character a surprising preference that can appear in dialogue or action; keep an original silhouette.

## Official character-site presentation

[Primary source](https://roshidere.com/)

Observe information priority; do not copy branding, artwork, copy or the entire layout.

## Adobe palette tools

[Primary source](https://color.adobe.com/create/color-wheel)

Separate character signature colors from functional interface colors and verify contrast independently.

## Live2D material separation

[Primary source](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)

Plan movable parts and exposed hidden surfaces only if layered Live2D production is the actual goal.

## VRM model features

[Primary source](https://vrm.dev/en/vrm/vrm_features/)

Confirm target format/version and pose/expression/gaze needs; a model file is not full tracking validation.

## Reduced-motion interaction guidance

[Primary source](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)

Retain content and interaction while reducing unnecessary motion; this is not a complete accessibility audit.

## Text contrast guidance

[Primary source](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

Measure actual text/background contrast where the text appears, rather than assuming a palette is readable.

## GSAP media-query lifecycle

[Primary source](https://gsap.com/docs/v3/GSAP/gsap.matchMedia%28%29/)

When GSAP already exists, inspect responsive/reduced-motion changes and cleanup; it is not a required dependency.

## Character/environment concept art

[Primary source](https://www.clipstudio.net/en/conceptart/art-style/)

Derive place, props, clothing and activity from the same world; extra turnaround sheets are optional.

## Beginner concept-art guide

[Primary source](https://www.clipstudio.net/en/conceptart/beginners-guide/)

Turn a broad theme into a concrete location with purpose, time and light.

## Landscape composition and silhouettes

[Primary source](https://www.clipstudio.net/how-to-draw/archives/163026)

Plan foreground, action space and background using simple shapes, then reserve readable text space.

## Character focal hierarchy in comics

[Primary source](https://www.clipstudio.net/en/comics-manga/design-tips/)

Reduce competing background detail to serve character focus, especially at mobile scale.
