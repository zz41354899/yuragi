# player / pause

Stop the animation loop and retain the current pose.

Import: `@yuragi/rig`

## Signature

```ts
(): void
```

## Parameters

No positional parameters.

## Returns

void

## Behavior, defaults and limits

Stop the animation loop and retain the current pose.

## Example

