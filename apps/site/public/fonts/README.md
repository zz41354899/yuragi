# Source Han Sans

Official Adobe Source Han Sans 2.005 variable WOFF2 assets, downloaded from:

- https://github.com/adobe-fonts/source-han-sans/tree/release/Variable/WOFF2/OTF/Subset
- https://github.com/adobe-fonts/source-han-sans/blob/release/LICENSE.txt

The unchanged TW and JP fonts are served locally. The accompanying SIL Open Font License is retained in LICENSE.txt. Only the active locale's primary font is requested, with the other font available as a glyph fallback.
